# Security

If you discover a security vulnerability in this project, please report it privately rather than opening a public issue.

## How to report

Open a [GitHub security advisory](https://github.com/alifarooqi/portfolio-blog-starter/security/advisories/new) for this repository. Include:

- A short description of the issue and its impact.
- Reproduction steps or a minimal proof-of-concept.
- Suggested fix (if you have one).

You should hear back within a few days. If the issue is confirmed, we'll work on a fix and coordinate disclosure timing with you.

## Scope

This template is a personal-portfolio starter. In scope: anything in the published source — `app/`, `lib/`, the build / deploy config, the `package.json` dependency tree. Out of scope: third-party services a fork user opts into (Medium, Google Analytics, Vercel, etc.) — report those upstream.

## Supported versions

Only the latest commit on `main` is patched. If you need a backport to an older version, mention it in the advisory.
